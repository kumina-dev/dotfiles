# Roadmap

The priority is a simple, reliable daily-driver desktop first. Initial versions should provide the essential functionality before adding polish, deeper integrations, or advanced options.

## First iterations

### Settings and Control Center

* [x] Wi-Fi settings
* [ ] Bluetooth settings
* [x] Display settings
* [ ] Appearance settings
* [ ] Keyboard settings
* [ ] Mouse settings
* [x] Sound settings
* [ ] Complete the basic Control Center

### Power

* [ ] macOS-inspired dropdown power menu

## After first iterations

* [ ] Calendar integrations and events
* [ ] Expand the power menu with system information and an "About This PC"-style view
* [ ] Add an Account section to Settings using the currently logged-in Linux system account

  * No separate Kumina account system
  * No cloud account requirement
  * System username and local account information are the source of truth
