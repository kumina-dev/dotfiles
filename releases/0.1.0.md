# KumiOS 0.1.0 — 18 October 2026

First release of the KDE Plasma Wayland daily-driver configuration for the existing
Arch installation. Local Git release only; no push or external publication.

## Desktop experience

- Compact top bar and centered Icons-only Task Manager dock.
- KDE Application Dashboard shared by the panel launcher, Meta+Space and launcher helper.
- Custom system menu and Control Center with native KDE About, Bluetooth devices,
  audio device selection and microphone settings.
- In-place layout reconciliation retaining existing panels and dock pins, with
  dependency checks, private backups and an explicit apply command.
- Native KDE window management, global application menu, clock and notifications.

## Installation and limitations

Follow [Plasma setup and recovery](../plasma/README.md). The setup utility targets
an existing KumiOS installation and requires its active audio service; it does not
install packages or provision a new machine. Bluetooth quick toggle assumes hci0;
use native KDE settings for detailed device management. Existing QML instances may
cache old code until a normal login or an explicitly approved Plasma restart.
No automatic restart, logout or authentication change is performed by setup.
Legacy Hyprland/GTK utilities remain in the repository without full release validation.

KUM-5–7 are accepted; KUM-8 remains open. Further releases should incorporate the
persistence result and any resulting fixes. No production deployment is included.
